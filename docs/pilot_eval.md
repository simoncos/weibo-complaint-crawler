# Historical 40-case pilot — exploratory and superseded

This file preserves the interpretation boundary of the earlier in-session
exercise. It is **not a reproducible benchmark result and must not be cited as
model performance**.

The earlier session reported, without committed case-level artifacts:

- 39/40 verdict agreement;
- 60% article exact match;
- 53.3% penalty-type Jaccard;
- 42.5% credit-point exact match;
- 1.12 credit-point MAE when both sides deducted credit.

The run used one in-session adjudicator that knew aggregate platform practice.
It did not preserve the sample, prompts, predictions, response metadata,
majority baseline or independent repetitions. Historical rumors may also have
been memorized. Because the public archive is overwhelmingly upheld, raw
verdict agreement is especially uninformative without class support and a
majority baseline.

No claim about model adjudication ability should be drawn from these numbers.
The replacement design is preregistered in `docs/benchmark_protocol.md` and has
not yet been executed.
